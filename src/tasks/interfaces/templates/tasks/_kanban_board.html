{# The daily board's Alpine component, registered globally. Lives in `base.html` because `Alpine.data` has to run before Alpine initialises, and the only script that reliably does is one the parser has already reached before boot -- the same arrangement as `_markdown.html`. Loaded on every page rather than only the board's, for the same reason SortableJS is: the registration is a few hundred bytes and the ordering problem is not worth a page that only works if the library happens to have arrived first. It costs nothing on a page with no board -- `Alpine.data` only defines a factory that nothing calls. #}
