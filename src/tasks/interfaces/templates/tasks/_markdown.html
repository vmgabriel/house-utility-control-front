{# The markdown renderer, shared by every page that shows a description. Loaded once from `base.html`, before Alpine boots, so the helper exists by the time the first `x-html` expression is evaluated. **Why `DOMPurify` is not optional.** `marked` is a CommonMark *parser* and does not sanitise its output; its own documentation says so. A description is text the user typed, and a user can paste anything into their own text box, including ``. Parsing that with `marked` and injecting it with `x-html` is stored XSS as soon as anyone else can see the text -- a shared goal's description, a subtask inherited from a decomposed task. `DOMPurify.sanitize` is what closes it. The alternative, sanitising in the BFF, was rejected for the reasons recorded in `src/tasks/interfaces/viewmodels.py`: it puts a second CommonMark implementation in the request path, and any hand-rolled tag stripper is one regex away from missing something. Both globals are checked before use. If the CDN is blocked or offline, the raw text is escaped and shown as-is -- a plain description is far more useful than an empty box, and the failure is visible rather than silent. #}
